🎓 Student Management System

Login Portal

Modular Browser-Based Architecture

A pure client-side Student Management System demonstrating enterprise design patterns: Layered Architecture (Presentation → Service → Repository → Persistence), IndexedDB storage, role-based workflows, and offline capabilities without any custom backend.

Open Application

🛠️ Layered Architecture

Strict decoupling: UI modules never directly touch IndexedDB; all operations pass through dedicated Services and Repositories.

💾 Browser Persistence

Powered by IndexedDB for relational object stores, sessionStorage for authentication state, and full JSON backup/restore.

👥 Role-Based Workflows

Role-protected routes and dedicated dashboards for Admin, Teacher, and Student profiles.
